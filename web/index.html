How It Works

Three steps, no setup

🔌

1. Plug In

Power from any USB port — your treadmill's built-in USB, a wall adapter, or a power bank.

📡

2. Auto-Connect

GarminBridge scans for nearby FTMS treadmills and connects automatically. No app needed.

⌚

3. Pair Watch

Add "GarminBridge" as a foot pod sensor in your Garmin's Settings → Sensors. Done.

FAQ

Common questions

Does it work with my NordicTrack / iFit treadmill?
Yes — NordicTrack and ProForm treadmills broadcast FTMS via Bluetooth. However, only one device can be the FTMS central at a time. If your iFit app is already connected to the treadmill, disconnect it first, then GarminBridge will auto-connect within seconds.
Why does my watch show 0 cadence / steps per minute?
This is by design. GarminBridge has no accelerometer, so it cannot count steps. Cadence is set to 0 in the RSC packet, which tells your Garmin to measure cadence itself using its built-in wrist or foot sensors. Your watch's cadence reading will be accurate from its own sensors.
Will two people be able to use it simultaneously?
Not with a single unit. Each GarminBridge bridges exactly one treadmill to one watch. For two runners on separate treadmills, each would need their own unit.
Does it track elevation / incline?
GarminBridge reads inclination from the treadmill (if the treadmill provides it via FTMS), but the RSC foot pod protocol has no inclination field, so it cannot forward that data to your watch. Your Garmin's built-in barometric altimeter will track elevation gain as you run. Inclination data is visible in the web analyzer.
My speed shows as about 39% of the actual speed. Why?
This is a known bug in firmware versions before v1.1.0. The RSC speed unit is 1/256 m/s, and the old firmware used 1/100 m/s — causing a 2.56× underreading. Update your firmware via the updater page to fix this.
Does it need internet or an app?
No internet connection, no app, no account. GarminBridge is a pure Bluetooth bridge. It works entirely offline and keeps no data — there is nothing to sync or subscribe to.
