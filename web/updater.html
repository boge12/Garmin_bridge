Firmware Updater

Keep your GarminBridge up to date with the latest firmware.

Latest firmware: v1.1.0 Fixes RSC speed unit bug (watch now shows correct speed). Adds inclination parsing, speed timeout, and serial debug output. Release notes →
Recommended method — works on any OS, any browser. No special software required. Just double-tap and drag.
1

Download the latest firmware

Get the .uf2 file from the GitHub releases page.

Download garmin_bridge_v1.1.0.uf2 →
2

Enter bootloader mode

Connect GarminBridge to your computer via USB-C. Then double-tap the reset button quickly (within ~0.5 s). The LED will flash and a USB drive named XIAO-BOOT (or GARMINBRG) will appear on your computer.

Single-tap vs double-tap: A single tap resets the firmware. A double-tap enters bootloader mode and shows the USB drive. If the drive doesn't appear, try again with a faster double-tap.
3

Drag and drop the .uf2 file

Open the XIAO-BOOT drive in your file manager and drag the .uf2 file onto it. The drive will disappear and GarminBridge will reboot automatically — usually within 2–3 seconds.

You do not need to eject the drive first.

4

Done!

GarminBridge reboots into the new firmware. The LED will turn blue as it scans for a treadmill. Open Arduino Serial Monitor (115200 baud) to verify the version number in the startup message.

Troubleshooting UF2: If the drive doesn't appear, make sure you're using a data USB-C cable (not a charge-only cable). Some cables only carry power. Try a different cable or USB port.
⚠️
Chrome only. WebUSB requires Chrome on desktop. Firefox, Safari, and Edge (non-Chromium) are not supported.
What this tab does (and doesn't do) WebUSB cannot write directly to the UF2 mass storage drive (the OS claims that interface). This tab can trigger bootloader mode for you — saving the manual double-tap step. You'll still need to drag the .uf2 file after.
